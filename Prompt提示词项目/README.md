## Background
    背景：对角色或任务进行详细描述，帮助大模型了解他们即将扮演的角色的背景知识
## Goals
    目标：列出此任务的主要目标或希望达到的效果
## Constrains
    约束条件：指明执行任务时需要遵守的规则或约束
## Definition
    定义：详细描述任务中涉及到的特定概念或名词，确保概念对齐
## Tone
    语气风格：描述完成任务时应采取的语言风格和情感基调，例如：“正式”、“随意”、“幽默”等
## Skills
    技能：列出执行此任务所需的技能和知识
## Examples
    示例：提供完成任务的实际示例或模板，有助于理解任务的要求和预期结果。通过具体示例，大模型可以更加
直接地理解任务的要求
## Workflows
    工作流程：描述完成任务的具体步骤或流程
## Outputformat
    输出格式：描述任务的预期输出格式，例如文本、图标、列表等。确保大模型知道如何格式化他们的答案，使
输出结果满足特定的要求或标准

    初始化：提供开始任务时的开场白或初始状态
